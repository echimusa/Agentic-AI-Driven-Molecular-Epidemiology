HOW TO RUN FROM THE SHIPPED DATA (about 2 minutes)
Install: pip install pandas numpy scipy matplotlib biopython ; R (base only).
    cd code ; cp ../data/* . ; mkdir -p figs1
    python ex1_1_discrimination.py        # expected: 4,811 isolates; Simpson's D 0.957 (serotype), 0.995 (PFGE), 0.994 (SNP cluster); W(PFGE -> SNP cluster) 0.438
    python ex1_2_snp_distance.py          # expected: median 6 SNPs; Spearman 0.317; AUC 0.668 for 'sampled within 30 days'
    Rscript ex1_2b_r_check.R              # expected: 195 genomes; 18915 pairs; median 6 SNPs; 17.1% within 2 SNPs; Spearman 0.317
    python ex1_3_design_simulation.py     # expected: at 36 months chain truth 0.372; estimates 0.106, 0.254, 0.351 at 20%, 60%, 100% sampled (about 1 minute; seeds fixed)
    python ex1_4_lineage_diversity.py     # expected: UK rarefied D 0.043 in March 2021 and 0.979 in October 2023; observed and rarefied D differ by at most 0.005
    python ex1_5_epidemic_process.py      # expected: direct pairs 1.01 SNPs on average and 40.5% identical; PPV of a 1-SNP threshold about 12% at 250 cases; no pairs between importations within 2 SNPs after 60 days (a few seconds)
    python ex1_5b_schematic_figures.py ; python ex1_6b_agent_diagram.py   # redraw Figures 1 to 3 and 9
    python ex1_6_agent_loop.py            # expected: 9 cases, 8 decided by the agent (5 correct, 3 wrong), 1 stopped at the quality gate
    python ex1_7_llm_agent_loop.py --mock # no key needed; expected: guardrails fire in 6 of 9 case runs, 4 cases go to a person, 67% agreement with the rule-table agent
    export ANTHROPIC_API_KEY=... ; python ex1_7_llm_agent_loop.py [--model claude-sonnet-5-5] [--runs 3]   # live run with a model (needs pip install anthropic; about 40 model calls)

HOW TO REBUILD FROM PUBLIC SOURCES (internet needed)
    Salmonella: download the Pathogen Detection metadata and cluster list (see Chapter 9) and run ex1_0_prepare_typing.py. Counts change as the NCBI table grows.
    Ebola: the alignment comes from Chapter 13 (download of BioProject PRJNA257197, MAFFT alignment).
    SARS-CoV-2: delete lapis_lineage_monthly.csv and rerun the query shown in the chapter against https://lapis.cov-spectrum.org/open/v2/ (one request per country and month; the script reads the cached file).

PROVENANCE AND LIMITS
- The 4,811 isolates with serotype, PFGE and SNP cluster are mostly food, animal and environmental isolates, not a random sample of Salmonella; PFGE patterns exist for only 5,731 of 911,210 isolates.
- The Pathogen Detection SNP cluster is a single-linkage group at 50 SNPs, not an outbreak definition.
- Sampling within 30 days is a proxy for closeness; the Ebola data contain no contact information.
- The design simulation is deliberately simple: constant incidence, one transmission rate, random sampling, genotype change only at transmission.
- Lineage names are revised over time, so later months have finer lineages; the open API holds only INSDC sequences.
- Hands-on 5 and the agent example use an infinite-sites mutation model, a constant rate, random sampling, and an assumed generation interval (mean 15 days, shape 4); the Ebola virus rate is the one estimated in Chapter 5. The agent example uses a rule table as planner so that it runs without a language model; its results come from one seeded draw. The language-model script was NOT run live in preparing this chapter (no model key was available): its harness was tested with a scripted stand-in, and the SDK call parameters were checked against anthropic 2.8.0. Live results will vary between runs and models.
- Figures 1 to 3 are original redrawings of ideas in the CDC toolkit module (the module's own images adapt material from The Washington Post, the Trevor Bedford group and Peter Thielen and are not reproduced). Figure 1 uses a raised mutation rate for legibility.
- Every DOI was resolved against Crossref on 10 and 13 November 2026. The Word file was validated and rendered to PDF (29 A4 pages); this LibreOffice has no math component, so the equations were not seen rendered; not opened in Word itself.
- The reference file Reference_chapter1.docx did not arrive with the request, so the chapter was built from the book plan and external sources.
