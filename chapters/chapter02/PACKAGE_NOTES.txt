HOW TO RUN FROM THE SHIPPED DATA (about 5 minutes)
Install: pip install pandas numpy scipy statsmodels scikit-learn matplotlib ; R with ggplot2 (the R scripts otherwise use base R only).
    cd code ; cp ../data/* . ; mkdir -p figs2
    python ex2_1_nested_case_control.py   # expected: Risk-set sampling mean estimate 0.399 at 1:2 (true 0.400); efficiency 0.59; infert OR 3.24 (spontaneous alone) and 7.29 / 4.09 (together); about 2 minutes
    Rscript ex2_1b_infert_clogit.R        # expected: the same odds ratios from the base R likelihood
    Rscript ex2_2a_batch_pca.R            # expected: PC1 explains 41.3% of the variance; t-test of PC1 against batch p = 3.2e-54
    python ex2_2_batch_effects.py         # expected: partly confounded design: naive 98.3% false positives, adjusted 5.5%; laboratory explains 34% of contig-count variance
    python ex2_3_stratification.py        # expected: naive 100% false positives; 2 PCs 7.8%; ancestry label 3.7%; restriction 4.5%
    python ex2_4_sampling.py              # expected: draft formula power 30-33% at alpha 0.05; with outcome variance 79-92%; 96.1% of open sequences from four countries

HOW TO REBUILD FROM PUBLIC SOURCES (internet needed)
    Cases: download owid-covid-data.csv from the Our World in Data repository and filter the 36 countries. Sequences: query https://lapis.cov-spectrum.org/open/v2/sample/aggregated with fields=date for each country.
    Salmonella: run ex2_0_prepare_assembly.py on the Pathogen Detection metadata (see Chapters 9 and 12). Counts change as the NCBI table grows.

PROVENANCE AND LIMITS
- The sample-size formula of the draft chapter is garbled in the uploaded file; ex2_4_sampling.py tests the reading N = (Z_a + Z_b)^2 / (2 p (1 - p) (ln OR)^2), which gave 30-33% power at 80% target, and the same formula with the outcome variance added.
- The open sequence counts are INSDC deposits only; many countries share through GISAID or keep sequences nationally, so the figures describe the open public sample and not sequencing capacity.
- Reported cases are not infections; a country with few reported cases (Kenya) looks well sampled.
- Simulations use stated, simple data-generating processes (Hands-on 1: constant hazard of 0.4 per SD and a 3% annual risk; Hands-on 2: a 1.5-unit batch shift; Hands-on 3: allele frequencies 0.10 and 0.45).
- The laboratory comparison for S. Enteritidis restricts to Illumina isolates; the platform field is almost entirely Illumina, so laboratory, not platform, is the batch.
- The reference list of the uploaded draft was checked against Crossref; corrected details are in the Sources section. Khoury 1999 could not be found.
- Every DOI was resolved against Crossref on 13 November 2026. The Word file was validated and rendered to PDF (18 A4 pages); not opened in Word itself.
