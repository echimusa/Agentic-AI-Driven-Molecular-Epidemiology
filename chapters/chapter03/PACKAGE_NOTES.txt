HOW TO RUN (about 5 minutes; Hands-on 2 needs internet)
Install: pip install pandas numpy scipy statsmodels biopython matplotlib ; R with ggplot2.
    cd code ; cp ../data/* . ; mkdir -p figs3
    python ex3_1_assembly_qc.py            # expected: robust length range 4.37-5.31 Mb; Moderate rule fails 4.82%, Strict 14.88%; laboratory failure 0.5% to 47.1%
    python ex3_3_snp_calling_simulation.py # expected: 20-fold depth: 84.2% callable, observed distance <= 2 in 40.8% of replicates (true distance 3)
    python ex3_4_quality_and_typing.py     # expected: adjusted odds ratio 0.66 for clustering and rate ratio 1.94 for AMR genes per 10-fold more contigs
    python ex3_2_read_qc.py                # downloads four FASTQ slices from the ENA (retries on HTTP 503); if the ENA is unavailable it falls back to the shipped *_demo.fastq.gz subsets (first 20,000 / 20,000 / 300 / 200 reads), which give slightly different numbers; full-run expectation: MiSeq error-probability mean Q20.4; Nanopore reads kept by the trimming rule 0%
    Rscript ex3_2b_per_base_quality.R      # needs per_base_quality.csv (shipped, or written by ex3_2_read_qc.py)

PROVENANCE AND LIMITS
- The public Salmonella table is already filtered by the Pathogen Detection pipeline; failure rates in a laboratory's own data are higher. The three rule sets are illustrations, not programme standards.
- Only the start of each FASTQ file is read in Hands-on 2; duplication and per-base profiles describe those reads. The MiSeq reads were trimmed before deposit.
- The Nanopore chemistry of the run analysed is not stated in the ENA metadata.
- The SNP-calling simulation is deliberately simple (independent positions, fixed hotspot rate, one reference, no mapping error).
- Hands-on 4 uses a random sample of 100,000 of 322,735 eligible Illumina isolates; laboratory (40 largest) and serovar (20 commonest) are adjusted for as fixed effects, the rest pooled.
- The AMR association with contig count is not explained by assembly statistics alone.
- Every DOI was resolved against Crossref on 13 November 2026. The Word file renders to 14 A4 pages in LibreOffice; it was not opened in Word, and the style-XML schema check of the validator reported errors on the pandoc-generated styles.
- The uploaded draft was used for its structure (typing, FASTQ and Phred scores, quality assessment, pre-processing, simulated example, comparison table); its reference list was checked and corrected (see Sources in the chapter).
