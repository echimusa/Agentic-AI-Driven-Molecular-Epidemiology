HOW TO RUN (about 2 minutes without part B)
Tools: MAFFT 7, IQ-TREE 2 and FastTree 2 on the path (for part B and for regenerating the trees); Python with numpy pandas scipy biopython matplotlib; R with ape.
    cd code ; cp ../data/* . ; mkdir -p figs5
    python ex5_1_distances_nj.py          # expected: NJ shares 34 of 40 (H3N2) and 42 of 50 (Ebola) ML splits; UPGMA Robinson-Foulds 0.48 and 0.49
    Rscript ex5_1b_nj_bootstrap_ape.R     # expected: NJ bootstrap >= 70 on 52.6% of the 57 internal nodes
    python ex5_2_likelihood.py            # expected: pruning code matches IQ-TREE log-likelihoods to 0.04 or better; AIC picks GTR, BIC picks HKY85
    python ex5_3_bootstrap_accuracy.py A  # real-data support; then C (needs the tables of part B, shipped); B regenerates the simulation tables
    python ex5_4_root_to_tip.py           # expected: Ebola best-root R2 0.584, 23.7 substitutions per genome-year; permutation p 0.001
    python ex5_5_agent_pipeline.py        # writes agent_report_*.md and agent_log_*.json
    python ex5_6a_extract_cds.py ; python ex5_6_modelling_detail.py   # expected: gamma rates add about 62 log-likelihood units to every model; relative rates of codon positions 0.59, 0.53, 1.88; JC fails the constant-sites and transition-share checks (about 1 minute; needs IQ-TREE)
To rebuild the trees: iqtree2 -s h3n2_ha_aln.fasta -m MFP -bb 1000 -nt 1 --prefix h3n2 -seed 1
                      iqtree2 -s ebola_aln.fasta -m MFP -mset JC,K80,HKY,GTR -mrate E,G4 -alrt 1000 -nt 1 --prefix ebola -seed 1

PROVENANCE AND LIMITS
- The uploaded scripts read https://raw.githubusercontent.com/colinmeir/molecular_epi/... which returns HTTP 404, so they do not run as uploaded. DistanceCalculator('jc69') raises a ValueError in Biopython 1.88. The CrewAI example (Chapter_5_3.py) was read, not run (crewai is not installed and needs a language-model key).
- The H3N2 sequences are a random draw of human isolates from the first 6,000 of 24,105 matching NCBI records; a later download can differ (the draw is seeded, but NCBI adds records). A first sample that included avian and swine hosts was replaced.
- The Ebola tree used by Hands-on 1 to 5 comes from a restricted model set (JC, K80, HKY and GTR with equal or gamma rates) and the SH-aLRT; Hands-on 3, part C, reruns it with the whole of ModelFinder (HKY+F+I) and the ultrafast bootstrap and finds the same tree. The agent report reads the whole-model run.
- Part B simulations use one substitution model (HKY, kappa 6), coalescent trees of 30 taxa and 20 replicates per setting; the bootstrap written here is for neighbour-joining only.
- Hands-on 5 holds the ML topology fixed; the adequacy check is a parametric simulation with four statistics (a parametric bootstrap, not a full posterior predictive check); IQ-TREE 2.0.7 has no built-in adequacy test.
- Root dates are regression intercepts and are not dated trees (Chapter 6).
- Every DOI was resolved against Crossref (56 DOIs on 14 November 2026). The Word file renders to 24 A4 pages in LibreOffice, but this LibreOffice has no math component, so the equations did not appear in the rendered preview; they read back correctly from the Word file (pandoc round trip) and were not seen in Word. The validator's schema check reports errors on pandoc-generated styles, page margins and equation separators.
- The uploaded draft was used for its structure (substitution models, distance methods, parsimony, ML, Bayesian inference, comparison table, agent example); its reference list was corrected (see the chapter's Sources).
