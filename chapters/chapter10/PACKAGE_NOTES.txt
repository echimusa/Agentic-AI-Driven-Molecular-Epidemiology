HOW TO RUN
Install: pip install pandas numpy scipy matplotlib python-docx python-pptx ; apt-get install plink1.9 bcftools tabix ; R with ggplot2 ; pandoc.
Check everything (about 2-4 minutes, needs the network only for --doi):
    cd review ; python validate_ch10.py --chapter ../Chapter_10_Host_Genetic_Epidemiology_and_GWAS.docx --doi --full
        default checks A-H: recomputation with code that does not import the chapter scripts; --full reruns the offline scripts in a scratch folder
    cd ../lecture ; python validate_slides_ch10.py MEPI7_Chapter10_Host_Genetics_GWAS_Lecture.pptx --data ../data --chapter ../Chapter_10_Host_Genetic_Epidemiology_and_GWAS.docx
Offline reruns from the shipped data (cd code ; cp ../data/* . ; mkdir -p figs10):
    Rscript ex10_2b_r_check.R ; python ex10_4_finemap.py ; python ex10_6_power_lambda.py ; python ex10_7_ancestry_3p21.py ; python ex10_8_admixture_mapping.py ; python ex10_9_notes_audit.py ; python ex10_10_diagrams.py
With internet (the scripts download what they need and keep it):
    python ex10_1_catalog.py            # two GWAS Catalog tables; counts change as the catalogue grows
    python ex10_2_qc_manhattan.py       # 336 MB harmonised file; expected lambda 1.045, 7 loci with P < 5e-8
    python ex10_3_stratification.py     # 205 MB chromosome 22 VCF; expected lambda 71.68 / 1.26 / 1.10
    python ex10_5_qc_structure.py       # the same VCF; about 3 minutes; expected 4,006 variants failing pooled HWE of 16,312

PROVENANCE AND LIMITS
- GWAS Catalog release tables: studies added to 15 October 2026; infection traits are found by keyword, so the groups are approximate.
- GCST011081 is a European-ancestry COVID-19 meta-analysis (hospitalised vs population): 9,986 cases and 1,877,672 controls as listed in the catalogue.
- Hands-on 3 simulates the trait (seed 10). Hands-on 5 uses 100,000 random biallelic SNPs of 1000 Genomes chromosome 22 (seed 10). PLINK makes A1 the minor allele of each subset unless --keep-allele-order is given; the script gives it.
- Hands-on 7 uses 50 kb either side of the lead variant and 2,504 people; estimates in groups where the allele is rare (AFR, EAS) rest on a handful of haplotypes.
- Hands-on 8 is a simulation, not a real cohort; its thresholds (1e-5 for admixture mapping, 5e-8 for variants) are assumptions stated in the script.
- Hands-on 9 recomputes numbers typed from course slides; 35 of 37 agree. The slides are course material with third-party acknowledgements (student slides and the genetic-epidemiology slides state no licence): they were paraphrased, not copied.
- The Word file and the deck were rendered with LibreOffice and were not opened in Word or PowerPoint; the lecture was not timed live.
